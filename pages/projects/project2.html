A-Level Revision Website

A focused revision hub that organizes A-Level subjects (Math / Physics / Chemistry) and provides lightweight planning and check-in tools — designed to be fast, simple, and usable without accounts or a backend.

HTML CSS JavaScript Revision Hub Planner Check-in No Backend GitHub Pages
Live Demo Source Code

Implementation / Design Approach

  • Information architecture first: organize revision content by subject and by resource type (notes, links, practice papers) so navigation stays intuitive.
  • Minimal friction: no login, no database, and no complex setup — the website should work instantly on any device.
  • Planner logic (client-side): take user inputs (papers left, time available, reserve days) and output a readable revision plan on the page.
  • Check-in flow: provide a simple daily check-in interface for habit building (works without persistence; can be extended with localStorage).
  • Reusable UI components: cards, badges, and consistent typography to keep the experience clean and predictable.

Key Features

  • Centralized revision links and subject-based navigation
  • Revision plan generator (inputs → plan output)
  • Daily check-in / progress UI
  • Responsive design for mobile and desktop

What I would improve next

  • Persist settings and progress using localStorage (last plan, check-in streak, selected subjects)
  • Add difficulty weighting (topic priority, weak areas, time-to-score efficiency)
  • Export the generated plan into a printable PDF view
  • Optional multi-day timeline visualization (calendar-style)
