Restaurant Ordering Website

A simple ordering website for a Western-style restaurant: select menu items, apply per-item customizations, add to cart, and generate an itemized checkout summary with total price and estimated preparation time.

HTML CSS JavaScript Cart State Customization Summary Generation GitHub Pages
Live Demo Source Code

Implementation / Design Approach

  • Clear user flow: Menu browsing → customization → add to cart → checkout summary.
  • Data model first: Each menu item has a name, category, price, and estimated prep time, so the UI and summary stay consistent.
  • Customization as structured options: Store selections like “no onion”, “extra cheese”, “less salt”, etc. as part of the cart item.
  • Cart state as the single source of truth: The cart array drives everything (rendered items, totals, and the final list).
  • Deterministic summary generation: Build an itemized list with quantities + customizations, compute total price, and derive an estimated time.

Key Features

  • Menu categories (mains / sides / drinks / desserts)
  • Per-item customizations (e.g., “no onion”, “extra sauce”, “ice level”, “doneness”)
  • Add / remove items, adjust quantity
  • Auto total price calculation
  • Checkout summary list for quick review

What I would improve next

  • Persist cart to localStorage so refresh doesn’t lose selections
  • Add an “edit item” dialog for customizations after adding to cart
  • Hook up a lightweight backend API for order submission
