Personal Portfolio Website (This Site)

A modern personal portfolio built for showcasing projects, skills, and timeline milestones. Designed with a clean card-based layout, theme switching (light/dark), and a modular structure that makes updates fast and consistent.

HTML CSS JavaScript i18n Theme Toggle Responsive UI GitHub Pages
Live Demo Source Code

Implementation / Design Approach

  • Component-like structure (without a framework): the homepage renders projects, timeline, and skills dynamically from i18n data, so content updates stay centralized.
  • Consistent design system: design tokens (colors, radius, shadows) make the UI cohesive and easy to extend.
  • Theme switching: light/dark mode is controlled via data-theme and persisted in localStorage for a stable user experience.
  • Internationalization-ready: a lightweight i18n loader supports language JSON files and triggers re-rendering after load.
  • Performance-focused UI: minimal dependencies, optimized layout, and responsive cards for fast loading on GitHub Pages.

Key Features

  • Project cards with detail pages (consistent layout + screenshots + links)
  • Timeline section for milestones and achievements
  • Tech stack badges grouped by category
  • Sticky glassmorphism navigation + smooth scroll
  • Dark mode with saved preference

What I would improve next

  • Add a dedicated About page with a longer story and downloadable resume
  • Refactor project content into a single JSON source to reduce duplication
  • Improve accessibility (focus states, ARIA labels, contrast checks)
  • Add a small “search/filter projects” control for scalability
Mind map is embedded as pure SVG (no dependencies), so it renders reliably on GitHub Pages.
